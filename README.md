# tech-samples

Zenn の技術記事で扱った仕組みを、そのまま試せる最小のサンプルとしてまとめています。
製品本体のコードは含みません。各フォルダは単体で動き、それぞれの README に組み込み手順があります。

| フォルダ | 内容 | 記事 |
|---|---|---|
| [`unity-webgl-ime-bridge/`](./unity-webgl-ime-bridge/) | Unity WebGL の IMGUI で日本語入力(IME)を使えるようにする HTML 入力欄のブリッジ | (公開後に追記) |
| [`python-motion-graphics/`](./python-motion-graphics/) | 生成 AI も動画編集ソフトも使わず、Python(NumPy・OpenCV・Pillow)と ffmpeg だけで 15 秒のモーショングラフィックス MV を作る(音楽も波の計算) | (公開後に追記) |

わたしたちは、性格診断で分身をつくり、日々の記録から気づきを届けるサービス「MetAIra」を作っています。
